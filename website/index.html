SPECIFICATION

Core design pillars

Trusted Kernel

A small Rust kernel checks all proofs with zero external dependencies and zero unsafe code.

Quantitative Erasure

Multiplicities (0, 1, ω) separate erased proofs, linear resources, and unrestricted values.

Cartesian Cubical Logic

Interval variables, cofibrations, path types, Kan operations, and Higher Inductive Types support native univalence.

Built-In Automation

An internal e-graph and linear arithmetic solver constructs proofs that the kernel checks independently.

Transactional Proof Search

Immutable proof states let tools test candidate proof steps in memory in parallel.

ASD-STE100 Documentation

Automated checks enforce Simplified Technical English across project documentation and release notes.

MODULAR WORKSPACE

Nine crates with strict boundaries

Crate Role
apollo-kernel Checks terms, universe levels, multiplicities, and cubical operations.
apollo-syntax Lexes and parses source files into syntax trees.
apollo-elab Elaborates surface syntax, unifies terms, and runs tactics.
apollo-query Runs incremental and parallel compilation queries.
apollo-auto Runs e-graph congruence and linear arithmetic automation.
apollo-codegen Erases proof terms and emits readable Rust source code.
apollo-lsp Serves editor and machine-readable proof interfaces.
apollo-cli Gives the unified apollo command-line interface.
apollo-wasm Compiles the checker and Rust extractor to WebAssembly with zero unsafe code.
